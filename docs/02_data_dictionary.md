# מילון נתונים ותפקידי עמודות

שמות עמודות באנגלית נשמרים כלשונם. רשומת זוג אינה רשומת נוסע. התכונות המורשות בפועל נאכפות ב־`safety.assert_features`.

| עמודה | משמעות | מקור/חישוב | שימוש מותר |
|---|---|---|---|
| first_id / second_id | hash של לוח הטיסה | FlightDate, חברה, מספר, שדות ויציאה מתוכננת | קישור בלבד |
| departure_date | יום יציאה מקומי של הרגל הראשונה | FlightDate | פיצול/קיבוץ |
| origin / hub / destination | מסלול זוג הטיסות | Origin/Dest | קלט |
| carrier | חברה מדווחת משותפת | Reporting_Airline | קלט |
| gap_minutes | מרווח מתוכנן בדקות | יציאה שנייה פחות הגעה ראשונה, UTC | קלט |
| duration_minutes | משך הנסיעה המתוכנן | הגעה שנייה פחות יציאה ראשונה | קלט |
| departure_hour | שעת יציאה מקומית ראשונה | CRSDepTime | מקור לתכונה מחזורית |
| weekday / month | יום/חודש המראה ב־UTC | חותמת יציאה מתוכננת | מקור לתכונה מחזורית |
| status | מצב זוג לפי שתי הרגליים | Cancelled/Diverted ועקביות זמנים | סטטוס בלבד |
| label_30 / label_45 / label_60 | אי־עמידה בסף; חסר במצב לא תקין | הגעה בפועל ראשונה מול יציאה מתוכננת שנייה | תווית בלבד |
| first_arrival_delay | איחור הגעה ראשונה | ArrDelay | ניתוח/תוצאה בלבד |
| second_departure_delay | איחור יציאה שנייה | DepDelay | תווית חלופית בלבד |
| hub_arrival_hour | שעת הגעה מתוכננת מקומית לשדה מעבר | CRSArrTime/תאריך ו־IANA | ניתוח נוסף; לא קלט במודל הנוכחי |
| same_tail | אותו זנב נצפה בשתי הרגליים | Tail_Number | אבחון בלבד |
| remaining_actual | מרווח עד יציאה בפועל | gap + DepDelay שנייה − ArrDelay ראשונה | תווית חלופית בלבד |

העמודות הנוספות לניתוח אינן מתווספות לקובצי הזוגות הקיימים או לאפליקציה. דוגמה ממשית: `reports/runs/part-a-data-20261126-01/input_examples.csv`. מפרט התכונות המחזוריות המלא: [רשומת הקלט](04_input_record_and_plan.md).
