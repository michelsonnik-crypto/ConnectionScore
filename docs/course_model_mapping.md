# מיפוי חומר הקורס לניסוי ConnectionScore

מקור עזר: הקובץ שסיפק המשתמש, ״דף נוסחאות - נושאים מתקדמים במדעי הנתונים - ניצן (1).pdf״, שני עמודים. הקובץ שימש למיפוי נושאים; אינו הוראה להריץ שיטה שאינה מתאימה לנתונים. הקובץ עצמו אינו מועלה למאגר.

| נושא בקובץ | שימוש בניסוי |
|---|---|
| Logistic Regression ורגולריזציה | שלושה ערכי C, בסיס רגיל, ספלאיינים, אינטראקציות ו־PCA |
| Naive Bayes | GaussianNB עם SVD ו־MultinomialNB עם דיסקרטיזציה של משתנים מספריים |
| Decision Tree | עומקים 4 ו־10, עם עלים מינימליים להגבלת התאמת יתר |
| Random Forest / Bagging | שני עומקים של Random Forest, ובנוסף ExtraTrees כהרחבה |
| Boosting / AdaBoost | AdaBoost עם גדמי עץ ועם עצים בעומק 2 |
| SVM | LinearSVC עם כיול כרונולוגי פנימי; לא הופעל probability=True שמשתמש בחלוקה פנימית אקראית |
| KNN | 25 שכנים, שקלול מרחק, הקרנת SVD וסקיילינג |
| PCA | הפחתה למספר רכיבים המשמרים 95% מהשונות במספריים בלבד; נלמד באימון |
| XGBoost | שלושה עומקים; מימוש של boosting של עצים, ולא שילוב של כל סוגי המודלים |
| בחירת תכונות / overfitting | שומרים תכונות לו״ז זהות, משווים רגולריזציה והרחבות מספריות; לא מוסיפים תוצאות בפועל |
| Bootstrap | קיים ניתוח רווחי סמך בבלוקים; אין לדגום זוגות תלויים כאילו כולם עצמאיים |
| מדדי סיווג | Brier ו־log loss למטרת הסתברות; AUC/AP וכיול לדיאגנוסטיקה. Accuracy לבדו אינו מתאים ליעד הלא מאוזן |
| Linear Regression | אינו המסווג הראשי ליעד בינארי; יכול לחזות איחור רציף בניסוי נפרד, שיחייב הערכת התפלגות זנב ולא רק ממוצע |
| K-Means / Isolation Forest / IQR | כלים לניתוח אוכלוסיות או איכות; אינם תחליף לתווית סיכון. לא מסירים איחורים קשים רק כי הם חריגים |
| HMM | דורש הגדרה של רצף מצבים ותצפיות; אינו מתאים ישירות לרשומת שתי טיסות לפני הזמנה |
| Collaborative filtering / recommendation systems | אין נתוני דירוגים או אינטראקציות משתמשים. ההמלצה כאן היא בחירה לפי הסתברות ואילוץ זמן |
| XAI / LIME | משימה נפרדת להסבר מודל שנבחר; לא מדד לבחירת המודל המדויק ביותר |

## גבולות ההשוואה

הניסוי רחב אך תחום מראש: 23 תצורות, שלושה חלונות זמן, עלייה של המובילים לאימון גדול, וחמש שיטות כיול. לא מבטיחים שנבדק כל מודל או כל ערך היפרפרמטר. אין oversampling לפני פיצול ואין חיפוש פרמטרים על TEST. כפיית כל נושא מהקורס על היעד תגדיל מורכבות בלי הצדקה מחקרית.

התוצאות מתועדות ב־reports/model_search.md ו־reports/model_search.json. ניסויים שנכשלו נשמרים בדוח ואינם נעלמים מההשוואה.
