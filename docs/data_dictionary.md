# מילון נתוני הקונקשנים

| שדה | משמעות | מותר כתכונת חיזוי? |
|---|---|---|
| first_id / second_id | SHA-256 מקוצר של מפתח טיסה מתוכנן | לא; רק זיהוי ובקרת חפיפה |
| departure_date | תאריך מקור BTS של הטיסה הראשונה | לפיצול ולקבוצות חלופות |
| origin / hub / destination | שדות המוצא, המעבר והיעד | כן |
| carrier | חברה מדווחת משותפת; לא בהכרח משווקת הכרטיס | כן |
| gap_minutes | יציאה מתוכננת של השנייה פחות הגעה מתוכננת של הראשונה, ב־UTC | כן |
| duration_minutes | הגעה מתוכננת לשער ביעד הסופי פחות יציאה מתוכננת ראשונה | כן |
| departure_hour | שעת יציאה מקומית מתוכננת, 0–23 | כן, קידוד מחזורי |
| weekday / month | יום בשבוע וחודש לפי מועד יציאה ב־UTC | כן, קידוד מחזורי |
| status | operated / cancelled / diverted / missing / invalid_actual_time | לא; מידע בדיעבד |
| label_30 / label_45 / label_60 | 1 אם היציאה המתוכננת השנייה פחות הגעה בפועל הראשונה קצרה מהסף | לא; יעד בלבד |
| risk_30 / risk_45 / risk_60 | תחזיות לסיכוי label=1 בקרב טיסות תקינות | פלט מודל, לא מקור |

הגעה בדיוק בסף נחשבת עמידה (תווית 0). איחור בטיסת ההמשך אינו משנה את היעד. ביטול קודם בסיווג להסטה, ואז סתירת זמן וחוסר. בכל סטטוס לא תקין התוויות ריקות; אין למלא אותן באפס.

## זמנים

זמן היציאה המקומי + אזור IANA של המוצא קובעים UTC. מוסיפים CRSElapsedTime לקבלת הגעה מתוכננת, ואז בודקים התאמה ל־CRSArrTime באזור היעד. הגעה בפועל מתקבלת מההגעה המתוכננת + ArrDelay ונבדקת מול ArrTime. זמן מקומי דו־משמעי או שאינו קיים בשעון קיץ נדחה במפורש. 2400 מטופל כחצות ביום הבא; איחור שלילי נשמר.

מיפוי השדות ל־IANA הוא snapshot של airportsdata ב־commit נעול. הוא אינו מרשם היסטורי; התאמת שעון BTS מפחיתה שגיאות אך אינה מוכיחה תוקף היסטורי מלא. ללא גרסאות לוח זמנים אי אפשר לטעון שהלו״ז המדווח היה זמין 30 יום מראש.

## מדגם ותלות

מזהה טיסה נקבע רק על פי תאריך, חברה, מספר, מוצא, יעד ושעת יציאה מתוכננת. 1/20 מהטיסות הנכנסות נבחרות לפי hash; כל חלופות ההמשך הכשירות שלהן נשמרות. מספר זוגות אינו מספר טיסות עצמאיות. גרסת המודל הראשונה מותאמת למדגם קבוע של עד 300,000 זוגות תקינים מתוך האימון, ללא סינון לפי היעד.

מיפוי סטטוסים ובדיקת קצה התקופה עשויים לסנן טיסות עם נתון שגוי או עם הגעה בפועל מעבר לגבול. אלה החרגות איכות/גבול מדווחות, ויש לבדוק רגישות להן בהמשך.
