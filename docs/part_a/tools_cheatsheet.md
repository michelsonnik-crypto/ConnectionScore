# דף הסבר לכלים ולשיטות

| כלי/שיטה | מה זה ולמה בפרויקט | שיוך קורס |
|---|---|---|
| ETL | קוראים מקור, מנרמלים ובונים רשומת זוג עם כללים שניתן לשחזר | מערכות BI — לפי מיפוי הצוות, דרוש אימות סילבוס |
| מיון וחיפוש בינארי | מסדרים המראות ומוצאים מועמדים בחלון מרווח בלי להשוות כל טיסה לכל טיסה | אלגוריתמים ומבני נתונים — לפי מיפוי הצוות |
| טבלת גיבוב | מזהה טיסה יציב מאפשר מניעת כפילות ובדיקת חפיפה בין פיצולים | אלגוריתמים ומבני נתונים — לפי מיפוי הצוות |
| זמן מקומי ו־UTC | שומרים משמעות נכונה של יום, חצות ואזורים שונים | רכיב הנדסי; אין שיוך קורס מאומת |
| סטטיסטיקה תיאורית | רואים התפלגות, שיעורים, מכנים וחסרים לפני שמסיקים מסקנות | יש לאמת שם קורס מדויק |
| Spearman | בודק קשר מונוטוני באמצעות דרגות; אינו מוכיח סיבתיות | הנדסת שירות — ייחוס הצוות, טרם אומת |
| Kruskal–Wallis / Mann–Whitney | משווים דרגות בין קבוצות בלתי תלויות; תלות בימים מונעת שימוש נאיבי ב־p | הנדסת שירות — ייחוס הצוות, טרם אומת |
| Friedman | משווה קבוצות על אותם בלוקים/ימים; מתאים יותר למבנה שדות משותפים | שיוך קורס טרם אומת |
| Wilcoxon מזווג | משווה הפרשים באותם ימים, עם הנחות שיש לבדוק | הנדסת שירות — ייחוס הצוות, טרם אומת |
| Bootstrap של ימים | דוגמים ימים שלמים כדי לא לשבור את התלות בין זוגות באותו יום | יש לאמת שם קורס; אינו מבטל תלות בין ימים |
| רגרסיה לוגיסטית | בסיס פרשני להסתברות של תוצאה בינארית | נושאים מתקדמים במדעי הנתונים — לפי דף הנוסחאות; שם קורס מדויק לאישור |
| עץ ו־Random Forest | לומדים חוקים לא ליניאריים; יער ממוצע עצים כדי לצמצם שונות | נושאים מתקדמים במדעי הנתונים — לפי מיפוי הקורס הקיים |
| XGBoost / HistGradientBoosting | מוסיפים עצים בהדרגה לתיקון שגיאות; מורכבות מוצדקת רק בשיפור נמדד | Boosting בנושאים מתקדמים — לפי חומר שנמסר |
| Brier | ממוצע ריבוע הפער בין הסתברות לתוצאה; נמוך עדיף | מדד ניסוי; יש לאמת אם נלמד במפורש בקורס |
| ROC-AUC | מודד דירוג של מקרים חיוביים מול שליליים; לא כיול ולא תועלת | נושאים מתקדמים במדעי הנתונים — לפי חומר הקורס |
| Average Precision | מסכם precision–recall ומתחשב בריכוז אירועים; לא מחליף כיול | יש לאמת שיוך מדויק |
| Sigmoid / isotonic | מתאימים מיפוי של ציוני מודל להסתברויות על חלון נפרד | שיטת מחקר; לא לייחס לקורס בלי מקור |
| פיצול כרונולוגי | לומדים מהעבר ובוחנים בתקופה מאוחרת; לא מערבבים זוגות על פני חודשים | עקרון תוקף מחקרי ומניעת דליפה |

משפט לכל הצגה: ״בחרנו כלי לפי שאלת המחקר והנחות הנתונים, ולא כדי להציג רשימה ארוכה של מודלים.״
