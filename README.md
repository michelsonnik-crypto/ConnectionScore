# ConnectionScore

מחקר להערכת הסיכון לזמן מעבר בלתי מספיק בקונקשנים בטיסות פנים בארה״ב.

## מצב נוכחי

נתוני מקור אמיתיים של ינואר 2025 הורדו ונבדקו. המאגר כולל מתאמי הורדה, דוח איכות, תיעוד מקורות ומסלול עבודה לצוות. אין עדיין מודל מאומן, תחזיות סיכון או אפליקציה.

המדד המתוכנן: האם זמן היציאה **המתוכנן** של ההמשך פחות זמן ההגעה **בפועל לשער** מותיר לפחות 30/45/60 דקות. אלה תרחישי מחקר, לא מינימום רשמי ולא מדידת עלייה בפועל למטוס. ביטולים, הסטות וחוסרים דורשים סטטוסים נפרדים.

## שחזור

נדרש Python 3.11 ומעלה וחיבור אינטרנט; ללא תלות בחבילות נוספות.

```bash
python scripts/fetch_data.py
python scripts/profile_data.py
```

קובצי המקור נשמרים ב־`data/raw/`; מדגם טיסות בשדות ATL/ORD/DFW ב־`data/processed/`. הקבצים הגדולים אינם נשמרים ב־Git. דוח קריא: [reports/data_quality.md](reports/data_quality.md). מקורות: [docs/sources.md](docs/sources.md).

המתאם מאמת חתימת קבצים שמורים ומשתמש בהם מחדש. OurAirports הוא מקור משתנה; הורדה חדשה עשויה לשנות את חתימתו. אין כאן אימות שכיסוי המקורות העתידי יישאר קבוע.

## עבודה בצוות

1. בעל המאגר מוסיף חברים באמצעות Settings → Collaborators.
2. לכל משימה יוצרים ענף ומגישים Pull Request עם הסבר ובדיקות.
3. שומרים קוד, הגדרות ודוחות ב־Git; לא מעלים סודות או קובצי נתונים גדולים.
4. מתעדים שינויי הגדרות מחקר ב־`docs/decisions.md` לפני השוואת מודלים.

## המשך

- מיפוי אזורי זמן, חצות ושעון קיץ; אימות זמני שער.
- בניית זוגות וקבוצות חלופות על פי לוח מתוכנן, עם תוויות וסטטוסים נפרדים.
- הרחבת הכיסוי וניתוח תיאורי והיסקי.
- בסיס הסתברותי ורגרסיה לוגיסטית; פיצול כרונולוגי ומניעת זליגת מידע.
- כיול וניסוי בחירת מסלול תחת אותה מגבלת זמן.
- ממשק עברי המציג תוצאות אמיתיות ומגבלות כיסוי.

טיפול בנתונים, סטטיסטיקה היסקית ולמידת מכונה הם שלושת רכיבי הפרויקט האקדמי. שלב הקליטה הנוכחי מספק את תחילת הרכיב הראשון בלבד.
